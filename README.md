# Abhinav Singh Chauhan — Personal Portfolio

A responsive personal portfolio built with **HTML, CSS and JavaScript**.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — styling, layout and responsive breakpoints
- `script.js` — mobile navigation, theme switcher and dynamic footer year

## Before submitting
1. Open `index.html` in a browser and test the page.
2. Replace `YOUR_EMAIL@example.com` with your real email address.
3. Replace `YOUR_GITHUB_USERNAME` and `YOUR_LINKEDIN_USERNAME` with your profile usernames. If you do not have a LinkedIn profile, remove that link.
4. Check that the education details, skills and project descriptions are accurate.
5. Add project repository/demo links if available.

## Upload to GitHub
1. Sign in at https://github.com and create a new **public** repository named `abhinav-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your live URL will look like:
   `https://YOUR_GITHUB_USERNAME.github.io/abhinav-portfolio/`
7. Open the live URL on both phone and computer and test all navigation links and buttons.
